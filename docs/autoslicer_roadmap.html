STEP 0・現已就緒 scripts/step0_blind_test.py

同曲風 5 好歌 vs 5 不想留盲測驗證

將同一主播、同一曲風的切片分別放進 good_clips/ 與 bad_clips/，循序執行全套修正版物理演算法：

  • Mel-Band-RoFormer 保留混響尾音分離（分離完立刻釋放顯存）
  • RMVPE 穩態音符過濾（濾除滑音與顫音尾，取核心中位數 Cents 偏差）
  • 12~15 dB RMS 能量門檻（排除原唱導唱墊音干擾）
  • 2 秒滑動視窗 Chroma + IOI 律動 CV / 鼓點門檻 + 高音破音/斷氣檢測
驗收輸出： 終端對照表（含 Cohen's d 分離度）＋ blind_test_report.csv。
STEP 1・零依賴輕量版 0 新套件 / 獨立檢視

基於 probs.npy 的結構異常預警

不改動生軸主線速度，直接讀取既有機率檔，快速揪出最明顯的結構性殘缺：

  • 自動標記 過短試唱放棄（例如 50~110 秒）
  • 自動標記 歌唱覆蓋率過低（排除前後奏仍大段空白）
  • 自動標記 段內多次低谷（後續可由 RoFormer 人聲軌二次確認是否為純間奏）
設計原則： 只做黃牌預警提示，不自動刪減片段。
STEP 2・主力工具落地 獨立 score_clips.bat

獨立體檢站：物理打分 ＋ 兩階段防幻覺插話偵測

Step 0 門檻校準完成後，封裝成獨立批次工具，拖入 .llc 與影片即可批次評分：

  • 循序執行：RoFormer 分離 → 釋放 → RMVPE＋物理打分 → 釋放 → 兩階段 Whisper 插話檢測
  • 兩階段防幻覺：先以高滑動 F0＋高音節率框出疑似說話段，再交給 large-v3-turbo 嚴格閾值轉寫
  • 回寫 Windows 安全標籤 到 .llc，並同步升級 sync_clip_metadata.py 正則前綴剝離
資源控制： RTX 5060 峰值顯存鎖定 < 6GB，20 首歌約 5~6 分鐘完事。
STEP 3・長線審美進階 選配模組

VocalVerse 2 (MuQ) 或個人品管分類頭
